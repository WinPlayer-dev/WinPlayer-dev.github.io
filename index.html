核心能力

插件，即音源

WinPlayer 本身不内置任何内容。一切曲目、播放地址与歌词，都来自插件——统一协议、沙箱运行、即装即用。

示意：每个插件可实现 search / getSongUrl / getLyrics 中的任意组合，核心统一调度。

插件接口协议

实现以下三个异步接口的任意组合，即可作为播放源被 WinPlayer 发现与调用。

接口参数返回用途
search()keyword: stringPromise<Song[]>聚合搜索的歌曲列表
getSongUrl()id: stringPromise<string>可播放的音频 URL
getLyrics()id: stringPromise<string>LRC 格式歌词文本

Song 对象字段：id / title / artist / album / cover。完整规范见 docs/PLUGIN-DEVELOPMENT.md。

theme.json 字段

主题 = 一份 theme.json。基调色相驱动整套配色推导，也可逐项覆盖。

字段类型说明
namestring主题名称，显示于主题列表
baseHuenumber基调色相（0–360）
colorsobject?可选，覆盖推导出的具体颜色

↑ 点一下色卡，整站强调色立即切换（baseHue 实时预览的思路）。完整规范见 docs/THEME-DEVELOPMENT.md。

从源码运行

准备以下环境后，四条命令即可在本地跑起来：

  • Node.js ≥ 18
  • pnpm
  • Rust 工具链（rustup）
  • WebView2 运行时（Win11 自带）

构建发行包：pnpm tauri build，产物为 MSI / NSIS 安装包。

系统媒体控制

SMTC 同步曲目与封面——键盘媒体键、任务栏浮层、锁屏界面都能直接控制播放。

原生应用质感

遵循 WinUI 设计规范：Mica 与 Acrylic 材质、原生控件动效，明暗主题完整适配。

主题随心换

可视化编辑器拾取基调色即可生成整套配色，也支持 theme.json 深度定制。

轻量跨平台

得益于 Tauri 2 与 Rust 后端，安装包与内存占用保持轻量，运行流畅。
